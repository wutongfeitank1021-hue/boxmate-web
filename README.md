# boxmate-web

Marketing site for 拳有 / BoxMate at [getboxmate.com](https://getboxmate.com).

Plain static HTML + CSS. No framework, no JavaScript, no analytics.

```
index.html          English home page
zh/index.html       Chinese home page
support/index.html  Support (English + Chinese)
privacy/index.html  Privacy policy (English + Chinese)
terms/index.html    Terms of use (English + Chinese)
assets/css/site.css Shared styles for the home pages
assets/img/         WebP images, OG image
assets/video/       Hero loop (muted, autoplay)
vercel.json         Clean URLs, www → apex redirect, cache headers
```

Deployed on Vercel (project `boxmate-web`). Push to `main` to deploy.
